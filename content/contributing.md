# Руководство по внесению правок (Contributing Guide)

Мы приветствуем любые исправления, дополнения и новые материалы! База знаний открыта для предложений сообщества, а весь контент хранится в виде Markdown-файлов в папке `content/`.

Вносить правки можно как прямо через браузер без настройки окружения, так и локально через Git.

---

## Варианты работы

### 1. Быстрые правки в браузере (опечатки, ссылки, короткие абзацы)

Самый простой способ, если нужно поправить существующий файл:

1. Откройте нужный `.md` файл внутри папки `content/`.
2. В правом верхнем углу окна просмотра нажмите иконку карандаша (**Edit this file**).
   * Если у вас нет прав на прямую запись, GitHub автоматически создаст ваш личный форк проекта.
3. Внесите изменения во вкладке **Edit**, проверьте вёрстку во вкладке **Preview**.
4. Прокрутите страницу вниз к блоку **Commit changes**:
   * Укажите краткое описание изменений (например, `fix: опечатка в описании`).
   * Выберите **Propose changes** (или *Create a new branch for this commit and start a pull request*).
5. Нажмите **Propose changes**, затем зеленую кнопку **Create pull request**.

---

### 2. Через веб-редактор GitHub (несколько файлов / новые статьи)

Если вы хотите отредактировать сразу несколько страниц или создать новый документ, не настраивая ничего на компьютере:

1. Нажмите клавишу `.` (точку) на клавиатуре, находясь на главной странице репозитория (или откройте `https://github.dev/Concept-Kult/wiki`).
2. В браузере загрузится полноценный интерфейс VS Code.
3. В дереве файлов слева перейдите в папку `content/`:
   * Вносите правки в существующие документы.
   * Для добавления страницы используйте иконку создания нового файла (например, `content/topic-name.md`).
4. Перейдите во вкладку контроля версий слева (**Source Control** / `Ctrl+Shift+G`), напишите комментарий к коммиту и подтвердите отправку изменений и создание Pull Request.


### 3. Локально через Git (для регулярных и объемных материалов)

1. Сделайте **Fork** репозитория в свой профиль GitHub.
2. Склонируйте свой форк локально:
   ```bash
   git clone [https://github.com/](https://github.com/)<ваш-username>/wiki.git
   cd wiki

```

3. Создайте отдельную ветку для ваших изменений:
```bash
git checkout -b update-content

```


4. Откройте папку `content/` в удобном редакторе (VS Code, Obsidian и др.) и внесите правки.
5. Зафиксируйте изменения:
```bash
git add content/
git commit -m "docs: добавить материалы по ..."
git push origin update-content

```


6. Перейдите на страницу вашего форка на GitHub и нажмите **Compare & pull request**.

## Правила оформления материалов

* **Формат файлов:** Все статьи оформляются в стандартном Markdown (`.md`).
* **Именование файлов:** Для новых документов используйте строчные буквы на латинице через дефис: `primer-nazvaniya.md` (`kebab-case`).
* **Метаданные (Frontmatter):** Если в начале файла присутствует блок метаданных в формате YAML (между `---`), сохраняйте его структуру:
```yaml
---
title: Название статьи
description: Краткое описание страницы
---

```


* **Изображения и медиа:** По возможности оптимизируйте загружаемые графические файлы и размещайте их в соответствии с общей структурой ассетов репозитория.

Спасибо за вклад в развитие базы знаний!
